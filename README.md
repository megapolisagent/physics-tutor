# physics-tutor-agent

Репетитор по физике в чате Cherry Studio, 8 класс. Сначала закрывает пробелы 7 класса,
из-за которых сейчас застряла школьная тема 8 класса, потом — обычная работа: домашние
задания с объяснениями. Тон — живой, с примерами из игр/техники/спорта, не сухой учебник.

Весь контракт агента — в `AGENTS.md` (в самом начале файла — «Кто ты и чего ты хочешь»,
дальше — механика: как ведёт занятие, как проверяет понимание, как работает с памятью).
Это текст, который вставляется в системный промпт ассистента в Cherry Studio (не запускается
отдельной программой). Доступ к файлам `memory/` и `knowledge/` — через MCP filesystem server,
подключённый к папке этого репозитория.

## ⚠️ Перед первым использованием

`knowledge/curriculum_7_8_grade.md` — программа по памяти, не сверена построчно с реальным
заданием ученика. Нужно до первого урока:
1. Загрузить реальное задание — повторение 7 класса, на котором сейчас виснет 8 класс.
2. Уточнить конкретную тему 8 класса в школе прямо сейчас.
3. Поправить `knowledge/curriculum_7_8_grade.md` под это.

## Установка и запуск (Cherry Studio)

1. Установить [Cherry Studio](https://github.com/CherryHQ/cherry-studio) (Windows: `winget install kangfenmao.CherryStudio`).
2. Подключить модель через OpenAI-совместимый API.
3. В настройках добавить MCP-сервер типа filesystem: команда `cmd`, аргументы `/c npx -y @modelcontextprotocol/server-filesystem "путь\к\этой\папке"` — путь именно к папке `physics-tutor-agent`, отдельно от любого другого репетитора в той же Cherry Studio (не путать пути между ассистентами).
4. Скопировать весь текст `AGENTS.md` в системный промпт ассистента.
5. Начать новый чат — агент сам прочитает `memory/` и `knowledge/` и определит, диагностика это или обычное занятие.

При изменении `AGENTS.md` — вставить обновлённый текст заново и начать новый чат.

## Структура

```
physics-tutor-agent/
├── AGENTS.md                       ядро агента — «кто ты», весь контракт и правила
├── knowledge/
│   ├── curriculum_7_8_grade.md     программа 7-8 класса + инвариант уровня сложности
│   ├── teaching_methods.md         банк живых аналогий по темам
│   └── tasks/                      растущий банк реальных заданий
├── memory/
│   ├── competency_map.md           главная память — статус ученика по каждой теме
│   ├── student_profile.md          профиль ученика, сильные/слабые стороны, стиль объяснения
│   ├── lesson_history.md           журнал занятий
│   └── session_state.md            состояние текущего занятия/очереди задач
└── examples/
    └── example-dialogue.md         пример урока: живая аналогия, NO SKIPPING, единицы измерения
```

## Память — четыре слоя

- **Competency Map** — статус каждой темы (не проверена / провал / частично / освоена), даты
  проверок, типичные ошибки. Определяет, какую тему агент выберет следующей.
- **Student Profile** — класс, текущая тема 8 класса в школе, сильные/слабые стороны, какие
  аналогии реально заходят этому ученику, план следующего занятия.
- **Session Memory** — состояние текущей задачи и очередь домашнего задания, перезаписывается
  в начале занятия.
- **Lesson History** — журнал занятий: дата, темы, что вызвало сложности.

## Ключевые правила контракта

- **MEMORY IS MANDATORY** — чтение памяти в начале занятия и её обновление в конце обязательны.
  Фраза «сохранил» без реального вызова инструмента записи запрещена — занятие не считается
  завершённым, если файл не изменился на самом деле.
- **DIAGNOSTIC / REGULAR** — пока в Competency Map остаются непроверенные/слабые темы 7 класса,
  агент сам выбирает тему и открывает занятие, не ждёт домашки. После — обычная работа с
  домашним заданием, где объяснение физического смысла — нормальная часть разбора, не исключение.
- **Живые аналогии** — новый термин или явление подаётся не сухим определением, а через вопрос
  из жизни ученика (игры, техника, спорт), формула — как следствие уже понятого, не наоборот.
- **NO SKIPPING** — нельзя объединять физическое действие (найти силу) и следующее за ним
  (подставить в другую формулу) в один шаг; перевод единиц измерения — тоже отдельный шаг.
- **Даты — только конкретным числом**, не относительной фразой вроде «через 5 дней» — такая
  запись верна только в день, когда её написали, и молча портится при следующем занятии.

Полный текст правил — в `AGENTS.md`.
