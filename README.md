# physics-tutor-agent

Репетитор по физике в чате Cherry Studio, 8 класс. Сначала закрывает пробелы 7 класса,
из-за которых сейчас застряла школьная тема 8 класса, потом — обычная работа: домашние
задания с объяснениями. Тон — живой, с примерами из игр/техники/спорта, не сухой учебник.

Устроен так же, как math-tutor-agent (тот же движок, см. `../math-tutor-agent`): весь
контракт — в `AGENTS.md`, память — в `memory/`, темы и аналогии — в `knowledge/`.

## ⚠️ Перед первым использованием

`knowledge/curriculum_7_8_grade.md` — ПЛЕЙСХОЛДЕР, программа по памяти, не сверена с
реальным заданием ученика. Нужно до первого урока:
1. Загрузить реальное задание — повторение 7 класса, на котором сейчас виснет 8 класс.
2. Уточнить конкретную тему 8 класса в школе прямо сейчас.
3. Поправить `knowledge/curriculum_7_8_grade.md` под это — какие темы 7 класса реально
   пререквизиты именно для этой темы 8 класса, не по порядку учебника вообще.

## Установка (Cherry Studio)

Та же схема, что для математики:
1. В настройках добавить MCP-сервер filesystem, путь — до этой папки (`physics-tutor-agent`),
   отдельно от математики (не путать пути между репетиторами).
2. Скопировать весь текст `AGENTS.md` в системный промпт нового ассистента.
3. Начать новый чат.

Уведомления о времени занятий в Телеграм — тот же скрипт-наблюдатель, что уже настроен
для математики (`../math-tutor-agent/scripts/lesson-watch.ps1`), он общий на все предметы
в одной Cherry Studio, отдельно ничего ставить не нужно.
